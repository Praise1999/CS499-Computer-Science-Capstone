Artifact Enhancements

Enhancement One: Software Design and Engineering

The first enhancement focused on improving the software engineering quality of the Grazioso Salvare dashboard. The application was refactored to improve modularity, maintainability, configuration management, exception handling, validation, and logging.

Sensitive database configuration was separated from application logic, and the AnimalShelter class was improved to provide clearer and more reusable database functionality.

View Enhancement One Narrative

Enhancement Two: Algorithms and Data Structures

The second enhancement focused on improving how the dashboard processes and organizes data. Rescue criteria were placed in a dictionary structure for efficient lookup, and the application was redesigned to reduce unnecessary database calls.

A master pandas DataFrame was used for repeated filtering, and vectorized operations were introduced to improve data processing. Sorting and filtering were also improved to provide more predictable and efficient results.

View Enhancement Two Narrative

Enhancement Three: Databases

The third enhancement focused on strengthening MongoDB interaction. The CRUD module was expanded with input validation, database-side sorting, projections, result limits, document counting, structured logging, and improved exception handling.

These improvements increased the reliability, maintainability, security, and efficiency of the application's database layer.
