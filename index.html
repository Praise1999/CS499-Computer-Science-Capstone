Professional Self-Assessment

Welcome to my Computer Science ePortfolio. This portfolio represents my growth throughout the Bachelor of Science in Computer Science program at Southern New Hampshire University. The projects and enhancements included here demonstrate my development in software engineering, algorithms and data structures, database development, secure programming practices, and technical communication.

Throughout the Computer Science program, I developed experience analyzing problems and designing computing solutions using several programming technologies and development approaches. My coursework strengthened my understanding of software development, object-oriented programming, database management, application testing, security, algorithms, and system design.

One of the most important lessons I gained from the program was that successful software development involves more than simply writing code. Developers must understand user requirements, communicate with stakeholders, evaluate design decisions, protect data, test solutions, and create systems that can be maintained and improved over time.

The artifact featured throughout this portfolio is the Grazioso Salvare Animal Shelter application originally developed during CS 340. The project uses Python, MongoDB, PyMongo, Dash, Plotly, and interactive data visualization to allow users to retrieve and analyze animal shelter information.

During CS 499, I revisited the original application and enhanced it in three major computer science categories: software design and engineering, algorithms and data structures, and databases. These enhancements demonstrate both the technical knowledge I developed during the program and my ability to evaluate and improve existing software.

Enhancement One: Software Design and Engineering

The first enhancement focused on improving the overall software architecture and maintainability of the Grazioso Salvare application. The original project successfully connected the Python application to MongoDB and displayed animal shelter data, but several areas could be improved to make the application more secure, reusable, and maintainable.

The enhanced version improved the AnimalShelter data access class by adding stronger input validation, exception handling, structured logging, type hints, improved documentation, and safer MongoDB connection handling. Configuration values were also separated from the main application logic.

These changes demonstrate my ability to evaluate an existing software system and apply software engineering principles to improve code quality, modularity, reliability, and security.

Enhancement Two: Algorithms and Data Structures

The second enhancement focused on improving the way the application processes, filters, and organizes animal shelter information. Efficient data retrieval and processing are important when applications operate on large datasets because unnecessary processing can negatively affect performance and scalability.

The enhancement improved the application's filtering and data-handling logic by organizing rescue criteria into reusable structures and reducing unnecessary repetition. The application uses MongoDB query operations and Python data structures to retrieve relevant records based on rescue categories such as water rescue, wilderness rescue, and disaster tracking.

This enhancement demonstrates my understanding of algorithmic thinking, data organization, query efficiency, and the trade-offs involved in processing data within the application versus retrieving targeted information directly from the database.

Enhancement Three: Databases

The third enhancement focused on strengthening the MongoDB database layer of the Grazioso Salvare application. MongoDB serves as the persistence layer for animal shelter records and allows the application to retrieve and manipulate information through the PyMongo driver.

The database enhancement expanded the original CRUD functionality and improved the reliability and efficiency of database interactions. The AnimalShelter class provides dedicated create, read, update, and delete operations while validating data and handling database errors.

The enhanced design also reflects security principles such as separating credentials from application logic and limiting unnecessary exposure of database configuration information. Together, these improvements demonstrate my ability to design and maintain a secure, reusable data access layer.

Skills Demonstrated

  • MongoDB
  • NoSQL database design
  • PyMongo
  • CRUD operations
  • Database queries
  • Data validation
  • Database exception handling
  • Secure credential management
