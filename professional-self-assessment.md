# Professional Self-Assessment

## Introduction

Completing the Computer Science program has allowed me to develop a combination of technical knowledge, problem-solving ability, communication skills, and professional experience that I can carry into the next stage of my career. My experience throughout the program has also changed the way I view computer science. I entered the program focused primarily on learning technical skills, but I now understand that successful computing solutions require more than writing functional code. They require understanding users, evaluating trade-offs, protecting data, communicating decisions, and designing solutions that provide meaningful value.

My professional experience has also influenced my development as a computer science student. Working in operations leadership at Amazon has required me to analyze performance, identify problems, communicate with different audiences, make decisions using data, and lead people through changing situations. Combining this experience with my computer science education has helped me recognize that my strengths are not limited to programming. I am particularly interested in opportunities where technology, project leadership, data, problem solving, and communication intersect.

## Collaboration and Communication

One of the most important skills I have developed is the ability to communicate technical and nontechnical information to different audiences. Computer science professionals rarely work independently of other people. Developers, managers, customers, analysts, and other stakeholders may all view the same problem differently.

My professional leadership experience has reinforced this lesson. In an operational environment, I regularly have to interpret data, identify performance gaps, communicate expectations, and work with others to determine appropriate actions. These experiences have strengthened my ability to translate information into decisions that other people can understand and act upon.

The CS 499 ePortfolio also demonstrates this ability. Instead of presenting source code without context, I created narratives explaining the purpose of each enhancement, the decisions made during development, and the skills demonstrated by the artifact. This provides both technical and nontechnical audiences with a clearer understanding of my work.

## Software Design and Engineering

Throughout the Computer Science program, I developed experience designing, modifying, testing, and evaluating software solutions. My coursework exposed me to multiple programming languages, development environments, and software design concepts.

The Grazioso Salvare Animal Shelter Dashboard included in this ePortfolio demonstrates the progression of these skills. The original project provided a functional application that connected a Python-based dashboard to MongoDB. During CS 499, I revisited the artifact and evaluated it from the perspective of a more experienced developer.

I improved the organization and maintainability of the application by separating responsibilities, improving configuration management, adding validation, strengthening exception handling, and improving documentation. Revisiting an older artifact helped me recognize how much my approach to software development has evolved. Functional code is important, but professional-quality software must also be readable, maintainable, secure, and adaptable.

## Algorithms and Data Structures

My coursework also strengthened my understanding of algorithms and data structures as tools for solving computing problems efficiently. Rather than viewing an algorithm only as a sequence of instructions, I learned to consider how the organization and processing of data affects application performance, scalability, and usability.

During the enhancement of the Animal Shelter Dashboard, I evaluated how animal records were retrieved, filtered, transformed, and displayed. I improved the processing of data and considered how database-side filtering could reduce unnecessary work within the application.

This enhancement demonstrated the importance of selecting an appropriate approach based on the problem being solved. Efficiency does not always mean creating the most complicated algorithm. In many situations, a simpler solution that reduces unnecessary processing and makes effective use of existing technologies provides greater value.

## Database Development

Database development became another important area of my technical growth. Through my coursework, I gained experience working with database systems and learned how applications interact with persistent data.

The Animal Shelter project uses MongoDB to store and retrieve animal records. During the database enhancement, I strengthened the data-access layer by improving CRUD operations, validating inputs, handling database exceptions, and separating database configuration from application logic.

This work helped reinforce the importance of designing database interactions intentionally. Database code affects application performance, reliability, maintainability, and security. I also gained a stronger understanding of why credentials and other sensitive configuration values should not be hard-coded directly into source code.

## Security

Security is an important responsibility in software development because even a functional application can create risk if data and resources are not appropriately protected.

One security improvement made during my capstone involved removing database credentials from the application's source code and loading them through environment-based configuration. I also incorporated validation and exception handling into the data-access layer.

These changes demonstrate a shift in my thinking about security. Security should not be something considered only after development is complete. Developers should consider possible vulnerabilities while designing, implementing, and testing computing solutions.

## How the Artifacts Work Together

The artifacts presented in this ePortfolio demonstrate different dimensions of my development as a computer science professional. The original Grazioso Salvare project represents my earlier ability to create a functional client-server application using Python, MongoDB, and data visualization tools.

The enhanced version demonstrates how my abilities have developed since the original project was created. Software engineering improvements increased maintainability and organization. Algorithm and data structure enhancements improved the way information is retrieved and processed. Database enhancements strengthened data access, validation, reliability, and security.

Together, the original and enhanced artifacts provide evidence of growth rather than simply showing a finished product. They demonstrate my ability to evaluate previous work, identify opportunities for improvement, implement changes, and explain the reasoning behind those changes.
